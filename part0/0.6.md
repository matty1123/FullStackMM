# 0.6: New note in Single page app

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a note and clicks Save
    Note over browser: JavaScript handles the form submission
    Note over browser: Add the new note to the displayed list

    browser->>server: POST /new_note_spa
    Note right of browser: Content-Type: application/json
    Note right of browser: Body contains the note as JSON

    activate server
    Note over server: Save the note
    server-->>browser: HTTP 201 Created
    deactivate server

  
```
